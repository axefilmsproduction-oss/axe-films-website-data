---

## ✦ Core Design Concept: "From Frame to Film"

The entire digital experience is built around a bespoke **three-dimensional camera aperture and stylized 'X' frame motif** rendered in real-time WebGL using **Three.js**:
1. **Preloader Sequence**: A sculptural 8-blade camera iris rotates and expands in 3D dimensional space as assets calibrate (0% to 100%).
2. **Hero Transition**: The 3D frame seamlessly dilates open and settles into the hero composition with organic mouse-tracking parallax and volumetric crimson lighting.
3. **Interactive Optical Lab**: An interactive f-stop simulator (`f/1.4` to `f/22`) that physically manipulates the 3D aperture blades in real time.

## ✦ Technical Highlights

* **Pure Web Audio API Sound Engine (`sound-fx.js`)**: Real-time sound synthesis for mechanical shutter clicks, low-frequency sub-bass whooshes, and interactive harmonic chimes. Zero external audio file dependencies.
* **Three.js WebGL Engine (`three-scene.js`)**: Architectural 3D aperture model, dynamic point lighting, particle dust simulation, and graceful fallback if WebGL is unavailable.
* **Custom Magnetic Cursor (`main.js`)**: High-precision mouse follower with contextual states (`EXPLORE`, `PLAY`, `HOVER`).
* **Melon.studio Floating Hover Preview**: Smooth mouse-following preview cards that reveal project stills on row hover.
* **Zero Build Step Required**: Clean, performant, standards-compliant HTML5, CSS3, and modern JavaScript.

## ✦ Instant 1-Click Deployment

### Deploy to Vercel
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import this repository (`axe-films-website-data`)
3. Framework Preset: **Other** (Root directory: `./`)
4. Click **Deploy**

### Deploy to GitHub Pages
1. In your GitHub repository, go to **Settings → Pages**
2. Under **Branch**, select `main` / `root`
3. Click **Save**
